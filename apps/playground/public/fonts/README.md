# Inter

`InterVariable.woff2` is the official variable font of Inter 4.1, byte for byte
as released (`web/InterVariable.woff2` in `Inter-4.1.zip`, rsms/inter, 15 Nov
2024). Its licence, the SIL Open Font License 1.1, is `Inter-LICENSE.txt`.

- zip: sha256 `9883fdd4a49d4fb66bd8177ba6625ef9a64aa45899767dde3d36aa425756b11e`
- font: sha256 `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`

The file is not modified or subset: the licence's reserved name would then stop
us calling it Inter. It has a weight axis (100 to 900) and an optical-size axis,
which the browser sets from the font size, so large type is Inter Display.
